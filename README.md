# Zap

A small Windows tray utility that keeps your computer from going to sleep, without changing Windows' power settings. Pause or quit it and normal sleep behaviour returns.

Zap is a Rust rewrite of [Caffeine](https://github.com/kyleleong/caffeine) by Kyle Leong, originally written in Object Pascal with Lazarus.

## Download

The latest build is always [`dist/zap.exe`](dist/zap.exe) in this repo. It's a single file with nothing to install; copy it somewhere permanent (for example `%LOCALAPPDATA%\Programs\Zap`) and run it from there.

## Usage

Zap lives in the system tray as a white lightning bolt.

- **Click** the icon to pause or resume. While paused the bolt is dimmed and your PC sleeps normally.
- **Right-click** for the menu:
  - **Pause / Resume**
  - **Keep display on** (on by default): also stop the screen from turning off. Your choice is remembered in `HKEY_CURRENT_USER\Software\Zap`. On Modern Standby laptops a screen that turns off looks like sleep, which is why this starts on.
  - **About Zap**
  - **Exit**: asks for confirmation (unless paused), then lets the computer sleep again.

Only one copy runs at a time.

## How it works

It calls the Win32 `SetThreadExecutionState` API with `ES_CONTINUOUS | ES_SYSTEM_REQUIRED` (plus `ES_DISPLAY_REQUIRED` when "Keep display on" is ticked), the same approach as Caffeine. Pausing clears the request. Zap waits on the Windows message queue, so it uses no CPU while idle.

## Building

Requires Rust 1.90 or newer, plus a resource compiler for the icons and version details: `windres` from MinGW for the GNU toolchain, or `rc.exe` from the Visual Studio Build Tools for MSVC.

```bash
cargo build --release
```

The executable is written to `target/release/zap.exe` (or to the `target-dir` set in a local `.cargo/config.toml`).

The icons are generated by `tools/make_icon.py` (needs Pillow), which renders each size separately so the tray icon stays sharp. Version details shown in Explorer come from `Cargo.toml`.

### Keeping `dist/zap.exe` up to date

A pre-commit hook rebuilds the exe and adds it to any commit that changes the code, icons or Cargo files, so `dist/zap.exe` always matches the source. Enable it once per clone:

```bash
git config core.hooksPath .githooks
```

## Differences from Caffeine

- A tray menu replaces the settings window, and clicking the icon pauses or resumes.
- No Lazarus/LCL runtime: one small, self-contained executable.
