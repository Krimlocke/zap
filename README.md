# Zap

A small Windows tray utility that keeps your computer from going to sleep, without changing Windows' power settings. Quit it and normal sleep behaviour returns.

Zap is a Rust rewrite of [Caffeine](https://github.com/kyleleong/caffeine) by Kyle Leong, originally written in Object Pascal with Lazarus.

## Usage

Run `zap.exe`. It lives in the system tray; click the icon for the menu:

- **Keep display on**: also stop the screen from turning off.
- **About Zap**
- **Exit**: asks for confirmation, then lets the computer sleep again.

Only one copy runs at a time.

## How it works

It calls the Win32 `SetThreadExecutionState` API with `ES_CONTINUOUS | ES_SYSTEM_REQUIRED` (plus `ES_DISPLAY_REQUIRED` when "Keep display on" is ticked), the same approach as Caffeine.

## Building

Requires Rust 1.90 or newer, plus a resource compiler for the icon: `windres` from MinGW for the GNU toolchain, or `rc.exe` from the Visual Studio Build Tools for MSVC.

```bash
cargo build --release
```

The executable is written to `target/release/zap.exe` (or to the `target-dir` set in a local `.cargo/config.toml`).

The icon is generated by `tools/make_icon.py` (needs Pillow), which renders each size separately so the tray icon stays sharp.

## Differences from Caffeine

- A single tray menu replaces the settings window; "Keep display on" is a checkable menu item that applies immediately.
- No Lazarus/LCL runtime: one small, self-contained executable.
